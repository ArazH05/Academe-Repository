# Academe-Repository
Academe is a full-stack academic management platform designed to help students organize their university life in one place. Built with Spring Boot, REST APIs, and a modern frontend architecture, the platform combines assignment tracking, course management, study collaboration, scheduling, and academic resource organization into a clean and scalable system.

The project focuses on real-world software engineering concepts including authentication, database relationships, role-based access control, API development, and responsive UI design. Academe is designed as a portfolio-level application that demonstrates backend development, frontend integration, and full-stack architecture using industry-standard technologies.
